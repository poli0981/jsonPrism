# Code of Conduct

This project adopts the **[Contributor Covenant, v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** by reference: its full text is
JSONPrism's Code of Conduct.

In short:

- Be respectful. Disagreement is fine; harassment and personal attacks
  are not.
- Assume good intent, but don't tolerate bad behavior.
- Keep discussion focused on the project.

The maintainer, Kokone ([@poli0981](https://github.com/poli0981)), is
responsible for enforcement. Report misconduct by email to
**[code@poli0981.dev](mailto:code@poli0981.dev)**, with links to the
issues, comments or messages concerned if you can.

Content on GitHub that breaks GitHub's own rules, including anything
posted by the maintainer, can also be reported to GitHub directly:
see [Reporting abuse or spam](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

Reports are handled confidentially. Following the Covenant's enforcement
guidelines, possible outcomes are a private correction, a warning, a
temporary ban, or a permanent ban from the repository.

Security vulnerabilities are not conduct reports; see
[SECURITY.md](SECURITY.md).

For the full text — definitions, scope, enforcement guidelines — see the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
